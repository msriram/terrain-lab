# Changelog

## Unreleased — showcase and living wildlife

- Project homepage, separate sandbox and wildlife demos, and a public field guide.
- Integrated animated wildlife with 33 selectable species and signature fauna for each of 26 worlds. Earth's randomized roster favors prey; predators trigger 2× escape speed, capture/respawn, and drag-to-safety protection.
- Original animated manta, seahorse, anglerfish, scorpion, crab, goat, ox, moth, bird, beetle, snail, serpent, and whale models with per-world encounters.
- Shared terrain/animal projector transforms, synchronized controller/projector
  wildlife, and editable browser sample terrain.
- Local model/animation/behavior modules, documented licenses, and a reproducible
  GitHub Pages build with automated simulation and browser checks.


## v0.1.0 — 2026-09-24

First portable Terrain Lab release.

- macOS Kinect v1 local bridge with automatic reconnect support
- Kinect-powered terrain renderer with 20 scene themes, contour lines, and water
- Separate laptop controller and full-screen projector output
- Four-corner sandbox calibration, projector rotation/alignment, and flat-reference correction
- Persistent per-rig settings plus portable configuration backup and restore
- GitHub Pages interface that connects only to a local Kinect bridge
