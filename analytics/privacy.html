Analytics privacy

Terrain Lab counts broad actions—page views, selected worlds, terrain edits, wildlife events, Kinect connection outcomes, and coarse performance bands—to help improve the sandbox. Counts are grouped by day, mode, world, and event. They are not unique-visitor counts.

We do not send Kinect frames, terrain shapes, screenshots, names, email addresses, precise locations, IP addresses, user-agent strings, referrers, or persistent visitor identifiers to the analytics database. Browser Do Not Track and Global Privacy Control are respected.

Aggregate counts are stored in Cloudflare D1 for at most 13 months, then removed automatically. Only the Terrain Lab owner can see the dashboard after signing in with GitHub. GitHub login is used only to verify that owner; the GitHub access token is not stored.

If you prefer not to send analytics, enable Do Not Track or Global Privacy Control in your browser.
